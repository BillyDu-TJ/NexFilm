# NexFilm P1.1 Real-Hardware Validation Checklist

Capture Corrected remains Experimental and default-off. Capture Characterized requires user target patches and independent validation; synthetic tests prove the mathematical chain only and do not establish real hardware or film-density accuracy. Scanner Input Profiles are independent and never promote a Capture Profile.

## Current Capability Naming

- [ ] Smart Auto is shown as **ProPhoto Estimate**.
- [ ] Dark/open correction without a fitted target is shown as **Capture Corrected Experimental**.
- [ ] A valid user-measurement `CaptureSeparation3x3` with train/validation diagnostics is shown as **Capture Characterized**.
- [ ] No result based only on dark/open/flat is called Density Measured or Density Calibrated.
- [ ] Scanner Input Estimate/Characterized provenance is shown separately from Capture and Density capability.

## Required Samples

- [ ] Record one complete setup: camera body, lens, copy stand, light source, gate geometry, and capture software metadata.
- [ ] Capture a dark frame at the same gain, exposure, and readout settings as the reference set.
- [ ] Capture an open-gate frame with the film path empty and illumination stable.
- [ ] Capture an optional flat-field frame. Do not apply it until an independent physical role is defined; report it as stored/not applied or unavailable.
- [ ] Capture film-base and full-exposure references through the same Profile, dark/open correction, orientation, and demosaic path.
- [ ] Capture representative base, content, and full-exposure RAW frames for density and saturation checks.

## Geometry and RAW Matrix

- [ ] Verify LibRaw orientation values 0, 3, 5, and 6 against a physical target; confirm Film Area coordinates and exported dimensions agree with Smart Auto.
- [ ] Verify active-area offsets for every supported Bayer filter pattern, including CFA phase at non-zero offsets.
- [ ] Record raw pitch, active area, masked optical-black rectangles, four black levels, four white levels, and saturation behavior.
- [ ] Verify bad-pixel masks, zero denominators, negative transmission, saturated samples, and reference geometry, exposure, ISO, camera, and CFA mismatches.
- [ ] Confirm X-Trans is visibly and explicitly routed to Smart Auto; no temporary demosaic is accepted.

## Digest and Recovery

- [ ] Record SHA-256 content and normalized metadata digests for dark, open-gate, and optional flat references.
- [ ] Change reference file content without changing its path and confirm automatic downgrade with a visible reason.
- [ ] Change RAW metadata, LibRaw version, algorithm version, camera body, lens, light-source identity, or geometry and confirm automatic downgrade.
- [ ] Restore the original conditions and confirm the next resolution automatically returns to Capture Corrected without rebinding the Roll.
- [ ] Force a transient decode/export failure and confirm preview and export use the same fallback contract and expose a warning.

## Platform and Scientific Sign-off

- [ ] Repeat the matrix on Windows and Linux with native LibRaw builds.
- [ ] macOS native CI/build remains **unverified** until a native run is captured; do not report cross-platform completion before that run.
- [ ] Compare Capture Corrected and Smart Auto orientation, crop coordinates, dimensions, thumbnails, and export output on the same frame set.
- [ ] Obtain independent optical or densitometric measurements before making any public claim that the result is scientific density calibration.
- [ ] Do not enable Capture Corrected by default or publicly until the real sample, dark, open, optional flat, film-base, and full-exposure matrix passes review.
