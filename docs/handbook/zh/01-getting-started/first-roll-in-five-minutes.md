## 步骤一：选择导入模式与登记元数据 {#import-workflow}

启动 NexFilm 后，默认呈现实时暗房风格的 **图库** 主视口。处理胶卷的第一步是将数字化扫描文件载入本地工作空间。点击顶栏右上角醒目的 **导入胶卷** 按钮，系统将弹出导入模式选择对话框。软件针对不同的拍摄与扫描习惯提供了两种导入路径：

选择 **按胶卷导入** 后，点击“选择文件夹”或“选择文件”，定位到底片存储目录。输入胶片型号（例如 `Kodak Portra 400`）与拍摄画幅（例如 `135`）。点击 **确认导入**，应用会即刻在本地数据库 `nexfilm_user.db` 中为该卷建立归档索引。需要牢记的是：导入阶段仅在本地生成轻量级缩略图与元数据记录，源文件始终保持物理只读，绝不会被移动、改名或复制。

## 步骤二：进入工作台与按需代理机制 {#proxy-generation}

在 **图库** 网格中，双击任意一张代表性画面的缩略图，或在选中该画面后点击顶栏居中的 **工作台** 视图标签，应用将无缝切换至高精度的显色处理空间。

首次进入工作台时，中心预览画布会短暂呈现加载指示器。这代表 NexFilm 正在触发底层的**按需 16 位线性代理生成流水线**。传统修图软件往往在导入阶段就对全卷数十张数十兆字节的相机 RAW 文件进行耗时长达数分钟的全量解码，极大挤占系统内存与磁盘吞吐带宽。NexFilm 采取了按需渲染架构：

1. **导入期零全量解码**：在图库浏览阶段，系统仅流式读取 RAW 容器内嵌的预览数据，实现秒级快速载入上百张胶卷。
2. **工作台按需生成代理**：仅当用户在工作台中激活某一张底片时，后台 Rust 引擎才调用 LibRaw 或高吞吐 TIFF 提取器，将原始拜耳数据解算为 16 位浮点精度的线性透射率纹理，并上传至 WebGL 2.0 显存纹理单元。
3. **实时 GPU 管线渲染**：中心视口完全依托 WebGL2 片段着色器实时计算光学密度对数反相、印片光加减色以及曲线映射，所有滑块调节均以 60 帧每秒的平滑帧率实时响应。

在画布交互方面，用户可以使用鼠标滚轮以鼠标光标指针为锚点进行平滑缩放；按住键盘空格键 <kbd>Space</kbd> 并拖动鼠标，可自由平移观察局部胶片银盐颗粒与对焦锐度；随时双击画布空白处，视图将自动恢复至全画幅适应视口。

## 步骤三：定义胶片有效范围与白边排除 {#film-area-definition}

进入工作台后，决定反相品质最关键的一道工序是精准界定**胶片有效范围**。在右侧检查器顶部展开“几何与范围”控制组，点击 **设置胶片范围** 按钮，预览画布四周将出现包含四角手柄与四条边线的手动框选矩形。

点击控制栏中的 **自动识别** 按钮，NexFilm 的边缘检测算法将快速扫描乳剂边缘与黑褐色画框交界处，自动拟合出推荐的裁剪边框。此时用户必须执行人工视觉复核。

确认框选边界严密贴合画面有效曝光边缘后，点击检查器中的 **保存范围** 按钮。系统将把几何坐标持久化写入数据库，并在画布上隐藏辅助调节线。

## 步骤四：自动反相与几何批处理下发 {#auto-invert-and-batch}

保存范围后，点击工具栏中的 **自动反相** 按钮。NexFilm 将在毫秒级时间内执行核心运算：

1. 引擎在裁剪框外围或预先登记的片基标记点处精确采样未曝光片基透射率，测定该帧底片的橙色色罩对数密度向量 $(D_{\min}^R, D_{\min}^G, D_{\min}^B)$。
2. 对选框内的所有像素执行对数变换与密度矩阵相减，将底片透射率数据投影至绝对光学密度空间。
3. 应用有界通道跨度响应模型自动建立正片对比度与初始三色平衡，一键展现自然通透的正片视觉预览。

如果这一卷底片是在固定翻拍架与固定片夹上连续拍摄的，底片在取景器中的物理画幅位置高度一致，此时无需对后续几十张画面逐一重复框选手柄。在已调校好范围的第一帧画面上，点击检查器底部的 **批量应用** 按钮。在弹出的分发选项中，勾选 **胶片范围与几何**，点击 **应用至全卷**。软件会自动将该帧的标准裁剪边界坐标瞬间分发至当前胶卷的所有画幅中，节省重复画框的工作量。

## 步骤五：暗房印片光微调与非破坏性编辑 {#printer-lights-tuning}

自动反相能够提供高精度的物理初始正片，但摄影师针对特定场景的创作意图往往需要个性化的影调与色彩平衡调节。在传统光学暗房中，调色师通过彩色放大机的红、绿、蓝三色滤光片微调各通道曝光量，这一经典设备被称为印片曝光机。

NexFilm 在右侧检查器中完整重现了 **暗房印片光** 模块。在光学密度域中，印片光调节严格遵循对数加减色原理：

1. **红光**：向右滑动增加红光，正片整体向红色调倾斜，阴影与中间调冷青色被对数消除；向左滑动减少红光，正片向青色偏移。
2. **绿光**：向右滑动画面呈现暖绿偏向；向左滑动减少绿光，中和树叶或荧光灯反射杂色，画面向品红色调微调。
3. **蓝光**：向右滑动增加暖黄补偿；向左滑动画面向纯净冷蓝微调，可用于校准黄昏或室内白炽灯底片的色温。

在调整参数时，NexFilm 提供了防误触滚轮设计：鼠标直接在滑块上方滚动不会改变数值，用户必须**先用鼠标左键单击一次目标滑块激活焦点**，此时使用鼠标滚轮方可进行微步数值步进。如果在微调过程中需要预览锐化细节，可按住键盘 <kbd>Alt</kbd> 键拖动锐化控制滑块（**数量**、**半径** 或 **细节**），预览画布将临时切换为高反差黑白边缘信号蒙版，松开按键即刻恢复全彩正片。

<div class="doc-callout">
    <div class="doc-callout-title">非破坏性历史与极简快捷键法则</div>
    <div class="doc-callout-body">在 NexFilm 中的所有操作均为完全非破坏性的内存状态记录。随时按下键盘撤销快捷键 <kbd>Ctrl</kbd>+<kbd>Z</kbd>（macOS 对应 <kbd>⌘</kbd>+<kbd>Z</kbd>）即可无损回退上一步修改；按下重做快捷键 <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> 或 <kbd>Ctrl</kbd>+<kbd>Y</kbd> 可重新恢复修改。在底片条可见时，使用键盘左右方向键 <kbd>←</kbd> 与 <kbd>→</kbd> 可瞬间切换至相邻画幅，所有参数均自动保存至数据库，无需手动点击繁琐的“保存”对话框。</div>

## 步骤六：样片单张导出校验与整卷交付 {#export-and-verification}

完成参数微调后，切勿直接盲目导出全卷上百张大图。标准暗房实践要求先输出单张高分辨率样片进行视觉校验。

点击顶栏右上角的 **导出** 按钮，系统将弹出针对当前画面的导出配置对话框：

1. **导出格式选择**：常规社交媒体分享或快速预览推荐选择高质量 **JPEG**（品质设为 95–100）；若后续需要将正片导入 Photoshop、Lightroom 或 DaVinci Resolve 进行二级无损精修，强烈推荐导出 **16-bit TIFF** 格式。
2. **色彩空间选择**：Web 发布与通用显示设备建议选用标准 **sRGB**；使用宽色域广色域显示器（如 Apple Studio Display 或专业印刷校色屏）的用户可选择 **Display P3** 或 **Adobe RGB**。
3. **色彩管理内嵌**：确保勾选 **内嵌 ICC 色彩配置文件**，保证导出的正片在各看图软件与浏览器中呈现完全一致的饱和度与阶调。

点击 **确认导出**，主线程将调度后台 Rust 渲染管道，在数秒内以全分辨率原片物理采样生成高质量交付正片。在系统的看图软件中打开该 TIFF 或 JPEG 文件，放大至 100% 仔细检查暗部噪点纯净度、皮肤色调自然度以及高光细节层次。

当确认首张样片的反相风格完全符合预期后，即可在顶栏点击 **导出胶卷** 按钮。在整卷导出面板中，用户可以定义文件名输出模板（例如 `{Roll}_{Seq}_{Film}`），并设定多线程并行渲染任务数。点击启动后，系统将自动依次调度全卷底片执行批处理导出，在几分钟内交付一整卷色彩纯正、阶调连贯的现代数字胶片资产。
