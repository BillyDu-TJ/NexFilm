## 两种日常工作模式深度决策对比 {#workflow-decision-matrix}

在胶片数字化暗房实践中，摄影师所面对的胶片来源与翻拍工况各不相同：有时是一整卷在相同光照条件下连续拍摄、连带片头完整冲洗的标准 135 胶卷；有时则是零散搜集的单张底片、无片头 120 中画幅底片或临时收到的测试样张。针对这些不同的工程输入，NexFilm 提供了两种既独立又可互相转化的核心工作模式：**按卷物理标定工作流** 与 **散张快速工作流**。

理解两种工作模式的底层机制与适用边界，是获得高效批处理吞吐量与严谨色彩一致性的前提。

对于日常整卷拍摄的纪实、人像或风光摄影，强烈建议采用按卷物理标定工作流；而对于日常零星扫描或快速验证翻拍布光，散张快速工作流则提供了最低的启动成本。

## 片基与片头双物理锚点标定机制 {#physical-calibration-anchors}

按卷工作流之所以能实现全卷色彩高度一致，核心在于建立了化学感光乳剂的双物理端值锚点：**未曝光透明片基（$D_{\min}$）** 与 **完全受光全黑片头（$D_{\max}$）**。

在 135 胶卷装机引片时，拉出暗盒暴露在强光下的那一段胶片在冲洗后会发生充分的银盐还原与发色，形成化学吸收上限，即最高饱和光学密度 $D_{\max}$；而在暗盒内部未曝光的片头末端或两帧缝隙处，乳剂未发生反应，仅保留片基塑料支撑体与残留染料色罩，形成最低光学密度 $D_{\min}$。两者共同界定了该卷乳剂在此次冲洗环境下的物理动态范围。

简单说，**片基**是这一卷的参考白色，**片头**是这一卷的参考黑色。它们不是画面内容，却是整卷色彩和反差的地基。也正因为如此，被拿来标定的画面会被单独标记，不参与后续正常调色。

标定操作在 **图库** 中完成：

1. 将整卷底片（包含翻拍的未曝光片基帧与黑褐色全曝光片头帧）导入为正规胶卷。
2. 在图库工具栏点击 **标定片头片基** 按钮，系统将进入交互标定引导流程。
3. 按照界面提示，先在包含纯净未曝光透明片基的缩略图上点击采样取样点，确认红、绿、蓝三通道的片基密度向量；随后切换至全曝光片头缩略图，在黑褐色区域点击采样全曝光密度。
4. 点击 **确认标定**，软件将计算并锁定当前胶卷的全局 $(D_{\min}, D_{\max})$ 物理跨度常数。

<div class="doc-callout">
    <div class="doc-callout-title">标定帧的自动排除与保护机制</div>
    <div class="doc-callout-body">在物理标定过程中被用户采样指定为片头或片基的特殊画面，仅具备光学仪器测量价值，并不包含实际拍摄景物。NexFilm 会自动在数据库中将此类画面标记为 <strong>标定参考帧</strong>。在后续进入 <strong>工作台</strong> 调色、执行 <strong>整卷批处理</strong> 以及最终 <strong>导出胶卷</strong> 时，系统将自动识别并跳过这些标定参考帧，防止无景物信息的黑褐色片头进入正片交付列表，避免浪费渲染算力与存储空间。</div>
</div>

## 整卷自动反相与共享白点防跳色 {#whole-roll-batch-processing}

在传统通用修图软件中批量处理一卷胶卷时，摄影师最常遭遇的痛点是“同场景跳色”。例如在同一逆光场景下连续拍摄的三张照片，第一张构图包含大面积天空，第二张构图特写了深色阴影，第三张为人像特写。如果对每张照片单独执行“自动色阶”或“自动曲线”，由于画面像素能量直方图分布截然不同，算法会对每张照片套用不同的拉伸比例，洗出的正片就可能第一张发灰发青、第二张过曝发红、第三张肤色蜡黄，同场景色调随之散掉。

NexFilm 依靠 **整卷批处理** 较好地解决了这一难题。其工程机理如下：

<div class="doc-callout">
    <div class="doc-callout-title">“共享白点”是什么</div>
    <div class="doc-callout-body">它不是在每张照片里各找一个最亮像素，而是先在整卷范围内找到真正的高光上限，再把这个上限作为所有画面的共同白点。这样，一张画面里天空多一点、另一张阴影多一点，都不会让自动反相把同一场景拉成完全不同的颜色。</div>
</div>

1. **共享片基色罩基准**：全卷所有画面统一采用前述标定的全局 $D_{\min}$ 密度向量执行色罩剔除，消除底片基底引起的单帧色差。
2. **全卷真实曝光扫描**：在启动整卷批处理时，算法并不孤立评估单个画面，而是快速预读全卷所有已保存范围的画面内容，在光学密度域中寻找全卷所有有效景物中最亮真实高光点的密度极值。
3. **建立全局共享白点**：以全卷最高有效亮度作为共享的白点端值，统一下发至全卷所有画幅。

由于整卷底片共享相同的物理白点与黑点映射常数，逆光天空不会因为局部构图占比变小而被过度提亮，深色阴影也不会因为缺乏高光而被强制拉灰。全卷所有画面的明暗反差与色彩倾向基本保持拍摄现场的光强关系，同场景跳色会明显减少。

## 120 中画幅与无片头底片的跨度回退机制 {#120-and-headless-fallback}

许多胶片摄影师经常处理 120 中画幅底片（由于背纸结构，冲洗后不存在强光曝透的引片段），或者处理已被冲洗店裁切除掉片头的 135 底片。在这类缺少 $D_{\max}$ 物理片头的工况下，强制要求片头标定显然脱离实际。

NexFilm 为此类情况设计了完备的**有界通道跨度响应平稳回退机制**：

<table class="doc-table">
    <thead>
        <tr><th>跨度响应区间</th><th>通道最大跨度比</th><th>数学控制模型</th><th>影调保障目标</th></tr>
    </thead>
    <tbody>
        <tr>
            <td><strong>死区区间</strong></td>
            <td>比值 $\le 1.15\times$</td>
            <td>不激活跨度拉伸，保持各通道自然对数线性比例</td>
            <td>防止同色温纯色场景（如纯蓝天或绿草地）因算法强行平衡而破坏真实色彩倾向</td>
        </tr>
        <tr>
            <td><strong>常规调节区间</strong></td>
            <td>$1.15\times < \text{比值} \le 1.35\times$</td>
            <td>执行平滑的非线性有界收敛加权，适度扩展动态范围</td>
            <td>在无物理片头参考时，自动对画面内容进行柔和的高光阴影延展，还原通透层次</td>
        </tr>
        <tr>
            <td><strong>安全截断上限</strong></td>
            <td>比值 $\ge 3.0\times$</td>
            <td>强制硬性截断，严禁任何单一通道跨度超过主通道 3 倍</td>
            <td>避免传统算法中“灰世界假设”常见的电平强拉死白、色阶断层与极端高光偏色</td>
        </tr>
    </tbody>
</table>

当遇到无片头底片时，用户无需在图库中进行片头标定，直接在工作台中点击 **自动反相**。算法会自动激活有界通道跨度响应模型：以测得的片基为底，基于当前画面像素分布在安全阈值（$1.15\times$ 至 $1.35\times$）内动态推算合理的高光上限，让画面保持明快清透，同时不会越过物理边界把影调拉裂。

## 散张导入的边界与后续管理 {#loose-import-to-archive}

散张导入为高频次、轻量级的单张处理提供了不小的便利。用户可以直接把若干扫描文件拖入窗口，马上开始调色。

不过它和按卷导入并不是同一套归档方式。散张画面不会出现在 **历史胶卷记录** 的胶卷卡片里，也不会参与整卷标定、整卷白点、接触印样和整卷批处理。它可以单张调色、单张导出，适合测试片、临时查看和零散素材，但不应被当成长期归档的主要入口。

如果一组素材本来就有明确的胶卷归属，最好从一开始就使用按胶卷导入。已经用散张导入处理过的画面，目前界面里没有“合并为正式胶卷”的入口；若要纳入胶卷档案，只能重新按卷导入。重新导入前请保留原来的调色记录或导出样片，以免重复劳动。

<div class="doc-callout">
    <div class="doc-callout-title">散张处理中的定位与重关联</div>
    <div class="doc-callout-body">散张底片同样严格遵守源片只读承诺。如果在操作系统中对散张底片所在的临时工作目录进行了清理或文件重命名，在图库中同样可以使用 <strong>定位文件</strong> 重新关联单个或多个文件，原有调整参数与历史快照完全不受影响。</div>
</div>

通过灵活组合按卷标定与散张快速处理，摄影师既能保持严谨的物理科学标准，又能从容应对多样化的底片数字化工作需求。
