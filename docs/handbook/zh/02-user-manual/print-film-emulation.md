## 暗房两段式物理显影映射机制 {#two-stage-physics}

在胶片摄影一百多年的暗房历史中，底片（Negative）从未被视为最终的视觉终点。底片在相机曝光后记录的仅仅是现实世界光线在银盐卤化物或染料层中引起的光学密度分布，其本质是高度线性的密度中间载体。在传统光学暗房中，一幅作品的最终诞生必须经历两个物理阶段：

1. **第一阶段：底片显影与密度反相（Scene Density Reconstruction）**
   消除底片色罩，依据三层感光乳剂的光学特性恢复客观场景的透射密度比值。这一步追求的是严谨、中性、无偏色的物理场景重建，确保阴影至高光的动态层次完整无损。
2. **第二阶段：相纸与印片介质二次曝光显影（Print Medium Mapping）**
   将反相后的正向光线通过放大机镜头，投射在特定的正片相纸（Photographic Paper）或工业电影印片胶片（Motion Picture Print Film）上。相纸乳剂特有的 S 型特征曲线（Characteristic H&D Curve）、非线性高光滚降、深沉的银盐最大反射密度（D-Max）以及特定染料的光谱吸收峰，赋予了胶片摄影令人沉醉的有机质感与审美调性。

> [!NOTE] 拒绝暴力曲线性质失真
> 市面上许多数字调色滤镜往往试图通过一步到位的激进高反差 RGB 曲线强行模仿胶片色彩，这种做法会导致暗部细节严重被压死、高光生硬截断并产生难看的色彩分离断层。NexFilm 坚持纯正的暗房两段式物理架构：第一步由核心引擎完成中立精确的密度域反相，第二步通过高精度三维查找表（3D LUT）将图像映射至真实的感光相纸响应空间中。

## 混合强度控制与自定义 3D LUT 加载规范 {#opacity-and-custom-luts}

在“印片胶片模拟（Print Emulation）”面板中，除了选择内置 LUT 外，NexFilm 还提供了细致的控制逻辑：

- **不透明度（Opacity 0–100%）**：
  默认值为 100%，代表完全映射相纸特性。用户可通过滑块进行精确的无级线性混合。当调低至 60%–80% 区间时，画面既保留了底层物理反相的中性真实动态，又微妙融入了相纸温润的高光滚降与色调沉淀，在写实纪录与暗房审美之间取得完美平衡。当选择“无内置 LUT（No Built-in LUT）”且不加载外部文件时，整个 LUT 渲染通道自动关闭。
- **加载外部自定义 `.cube` 文件**：
  点击面板中的“Load Custom LUT”按钮，用户可加载第三方标准 3D LUT 文件。NexFilm 严格遵循行业通用的 Adobe `.cube` 规范，支持 17×17×17、33×33×33 以及 65×65×65 晶格分辨率，底层采用硬件三线性插值实时计算。

> [!WARNING] 严禁误用影视摄影机 Log 还原 LUT
> 检查器中的 3D LUT 模块位于渲染管线的成片输出端，其输入数据为已经完成密度反相的正片空间。切勿直接套用专为数字摄影机（如 ARRI LogC、Sony S-Log3）设计的 Log-to-Rec709 转换 LUT，否则会导致严重的饱和度过载与色彩相位颠倒。

## 纯粹银盐黑白暗房工作流实战 {#bw-darkroom-workflow}

对于黑白摄影创作者而言，NexFilm 提供了一套高度拟真传统暗房可变反差相纸的工作流：

1. **进入工作台切换至 B&W 模式**：
   在检查器模式开关中点击 **B&W**。底层管线将三通道直接并入单通道密度域，消除彩色色罩干扰，直方图自动切换为纯单色亮度分布。
2. **界定胶片范围并自动反相**：
   框定有效成像矩形，点击 **Auto Invert**。引擎依据底片测得的最小与最大密度解算出标准的黑白正片。
3. **选择 Ilford MGFB 反差号数**：
   在“印片胶片模拟”下拉菜单中，摄影师可直观模拟暗房放大机更换滤色片的效果：
   - 若拍摄的是雨天、阴天或反差偏平的负片，直接挂载 `Ilford MGFB 3` 或 `4`，中灰阶调瞬间被收紧，高光亮斑跃然纸上；
   - 若拍摄的是烈日强光直射的场景，负片本身反差过大、暗部容易死黑，挂载 `Ilford MGFB 0` 或 `00`，深层暗部细节瞬间舒展释放。
4. **配合细节面板的银盐颗粒保护**：
   在细节面板中将锐化蒙版调至 40 以上，既保留了相纸号数带来的强烈明暗冲击，又不会放大底片固有的银盐颗粒底噪。

## 印片模拟与下游工作流的协同边界 {#downstream-interop}

理解印片模拟与下游专业后期软件（如 DaVinci Resolve、Adobe Photoshop）的分工边界，是构建现代专业色彩管线的关键：

- **立足 NexFilm 独立完成出片**：
  若工作流的最终目标是直接导出高质量图片并在社交网络分享、提交客户交付或送交艺术微喷打印，建议在 NexFilm 工作台内直接选定心仪的相纸或电影印片 LUT，并配合 16-bit TIFF 或 sRGB JPEG 完成全套调色闭环。
- **交接达芬奇或影视调色管线**：
  若胶片素材后续需要进入 DaVinci Resolve 与数字电影摄影机素材共同混剪调色，**建议在 NexFilm 中将印片胶片模拟设为“无内置 LUT”，并导出 16-bit Linear TIFF 或 Linear DNG**。通过将纯粹的无偏色线性正片交付下游，调色师可在达芬奇内部的 ACES 或 DaVinci Wide Gamut 宽色域管线中自由施加 Kodak 2383 等电影打印 LUT，从而确保全片色彩管线的统一可控。
