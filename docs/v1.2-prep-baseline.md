## 1. 换行符幻影改动:核实与根治

**现象**:用户环境约 68 个文件显示为修改,内容疑似仅换行符不同。

**核实**(2026-11-03,main `c8480b5`):工作区 56 个 CRLF + 13 个 mixed = **69 个**文本文件,逐个与索引做去 CR 字节级对比——**全部一致,零真实内容差异**。仓库索引本身完全健康(222 个文本文件全部 LF,0 个 CRLF/mixed)。

**根因**:Windows 系统 Git 配置 `core.autocrlf=true`(检出时 LF→CRLF)与 Mac/无转换环境混用;转换关闭的环境里,工作区 CRLF 文件与 LF 索引字节不等,即成幻影改动。本机因 stat 缓存与转换开启未显现,分叉出现在另一侧环境。

**处置**:

1. 本机无需丢弃(强刷后 0 差异);
2. 根治:新增 `.gitattributes`(提交 `3032fbc`),`* text=auto eol=lf` + 二进制类型显式标记。`git add --renormalize .` 影响为 **0 个已跟踪文件**(索引原本已全 LF),远低于"大量变动需停下报告"的阈值,故正常提交;
3. 本机工作区已一次性重写为全 LF(`git ls-files --eol`:222 w/lf + 56 二进制 + 2 none,零 CRLF/mixed);
4. **Mac 侧操作**:拉取 main 后若仍见幻影改动,执行一次 `git restore .` 即清,此后不再复发。
