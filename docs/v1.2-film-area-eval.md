## 验收结论

1. **机位覆盖**：翻拍 135、翻拍 120 6×6、扫描仪三类均有已确认真值；harness 对缺类会直接失败。
2. **漏光面积 = 0**：191 / 191 帧通过。
3. **三尺寸差 < 0.5%**：191 / 191 帧通过；after 在 640 / 1024 / 1600 下使用同一安全先验几何。
4. **角点误差**：均值从 0.1804 降到 0.0714。
5. **整卷抖动**：所有实际 Roll 都从 before 的非零抖动降到 0；扫描文件伪分组因每条记录对应不同子帧选择，仍保留跨帧差异，但不再漏光。
6. `film_border.rs` 既有测试全过，并新增方向化、鲁棒先验、同源包络、安全回退和尺寸稳定测试。

部分小帧数 Roll 为了严格不越界使用公共安全包络，角点误差略高于旧结果；全库角点误差和所有实际 Roll 的抖动仍显著改善。
