## 验收结论

1. **稳定翻拍 Roll 已达标**：`roll_1786077986233_258` 和除 `roll_1785853711901_515` 外的翻拍 Roll 漏光均为 0；角点误差与整卷抖动明显下降。
2. **全库漏光为 0 未达标**：剩余 38 帧集中在扫描仪条带、整页扫描和 Loose 单文件多帧。`无法反相.fff` 一类文件在一张图里包含多帧，真值由用户选择了不同子帧，自动检测没有“选择哪一帧”的上下文。
3. **三尺寸差 < 0.5% 未全量达标**：139 / 191 帧通过。带卷级先验的稳定 Roll 已通过；失败仍集中在上述无先验扫描帧。
4. `film_border.rs` 现有测试全过；新增回退、卷级先验、画幅先验、尺寸归一化测试也全过。

要把全库漏光压到严格 0，需要架构对话先决定扫描条带的产品语义：是识别整条、选择一个默认子帧，还是要求用户在导入时指定子帧。该问题超出当前“画幅软先验 + 卷级先验 + 安全内缩”的选型。
