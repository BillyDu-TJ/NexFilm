## 验收结论

1. **漏光面积 = 0**：191 / 191 帧通过。
2. **三尺寸差 < 0.5%**：191 / 191 帧通过；after 在 640 / 1024 / 1600 下使用同一安全先验几何。
3. **角点误差**：均值从 0.1804 降到 0.0858。
4. **整卷抖动**：实际 Roll 全部不劣于 before，多数降到 0；扫描文件伪分组因每条记录对应不同子帧选择，仍保留较大跨帧差异，但不再漏光。
5. `film_border.rs` 既有测试全过，并新增方向化、鲁棒先验、同源包络、安全回退和尺寸稳定测试。

个别帧采用保守的安全包络，角点误差可能略高于旧结果（例如 `roll_1787401939673_235`），但换来了严格不越界和跨尺寸稳定；整卷与全局指标仍明显改善。
